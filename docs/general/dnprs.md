# DNPRs: expansion

*Rules: DNPR Expansion p.41, §13.3 p.35, Owned p.28. Sources: Discord, Oct 2026 (links to be added).*

## Where a DNPR can expand (🔵 p.41)
A DNPR token goes on a Province or Territory that is **adjacent to the DNPR**, and that is not a Capital (unless it's an NPR's last Province), **not Occupied**, **not Owned by the DNPR's Ally**, and **not a PR's Core Province**. If the Province has a Town or Vassal token, the DNPR token goes **underneath** it, which makes the Province a Core of the DNPR, and the Province gets Unrest. A DNPR token can never be placed on a PR's Core (§13.3).

## Adjacency is drawn only from Owned Provinces (OPG, 5 Oct 2026)
- 🟢 Mikhs: a DNPR **can** expand into Provinces Owned by players. The base rule is that it can't expand into **Core** Provinces, and there is an optional rule that allows that too.
- 🟢 Mikhs: the expansion **can't originate** from a Province Owned by a PR. The DNPR token under it only marks it as the DNPR's Core. If it is Liberated (for example by Rebels), it becomes an Owned Province and can then be used for adjacency.
- 🟡 Miroku20X6: "you can only trace Adjacency by what you Own."
- 🟡 damifoe: a DNPR can't expand from its **Occupied** Provinces either.
- Example (OPG): Florence expanded Pisa → Bizerte (legal), then Bizerte → Kabylia, Mitidja and Oran, all owned by PRs. The second set was illegal.

## Expansion onto a Vassal with a Royal Marriage (debr41, Oct 2026)
- 🟡 Mikhs: the Vassal stays the player's Vassal and becomes a Core of the DNPR. If two Provinces share the DNPR token they are the **same Realm**. In that case Mikhs thought you'd **lose the Marriage**, since you had it with the Realm that ceased to exist and not with the existing one. He said "I think", so this is an open question ([Q16](../open-questions.md)).
- The new Realm's religion follows its Capital Area (Orthodox in that example). Mikhs: "I think you can RM all Christians", but he wasn't sure.

## Houserule (🟣 not official)
Rafiki von Chybi: when a DNPR **Owns all** the Provinces in an Area, the Area converts to the DNPR's religion (for example Castile fully conquering Andalusia makes it Catholic). Mikhs: "Not a bad one." Applies only when the DNPR **Owns** the Area, not with player Towns or Vassals there, and only checked when it fully expands.
