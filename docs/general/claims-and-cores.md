# Claims and Cores in the same Area

*Source: Discord thread "Peace order", 21 Sep 2026 (message link to be added). Rules: Core tokens, p.21; Game Concepts p.2.*

**Question (insearchofescapism):** after a war, can a PR have a Core token and a Claim token in the same Area?

**Answer:** **No.** 🟡 damifoe: Core tokens count as Claims, and Claims are limited to one per Area per Realm. Miroku20X6 first said yes ("can help with removal of Unrest"), then agreed with damifoe. The asker had looked for the rule and couldn't find it.

**Rulebook support (🔵):** the Core token text says that placing one **displaces any Claim token or other Core token already in the same Area**. The PDF text extraction garbles the Claim symbol, so confirm the exact wording on the printed page (p.21) before quoting it.
