# Two allied PRs, one human enemy

*Played in the **Steppes & Stones** expansion. The repo assumes the base rules apply; we haven't checked the expansion rulebook.*

## Setup
| | |
|---|---|
| Ottomans, Persia | PRs, each at war with the Mamluks (human). Persia called its PR ally **Great Horde**. |
| Board | Ottomans and Mamluks hold nothing in each other's Areas. **Great Horde** occupies 3 Mamluk Provinces in one Area, **Persia** 3 in another. |
| Units | Great Horde has **2:1** against the Mamluks. Persia does not. |

## Resolution
1. **Ottomans vs Mamluks:** Automatic White Peace. Each PR loses 1 Prestige and a Truce is placed.
2. **Great Horde and Persia resolve peace with the Mamluks individually.** Ignore that they are allies: allies resolve jointly only when the ally is an **NPR Active Ally** (🟡 Miroku20X6; compare [PR-013](013-two-prs-one-npr.md)).
3. **Great Horde** has a Partial Victory (2:1 vs a human). It can enforce **Keep Current Board State**: simply keep what it occupies, or Liberate Provinces that aren't Mamluk cores.
4. **Persia** can't enforce anything: no 2:1 and no Surrender. It can only try to **Negotiate**. If nobody agrees, the war continues.
5. The players could make a **verbal deal linking the two peaces**, but it is **not enforceable**, because peace resolves in Turn Order.
