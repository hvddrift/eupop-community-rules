# A Total Victory that only appears after another player's peace

*Peace is resolved in Turn Order, so one player's deal can change the state of another player's war.*

## Setup
| | |
|---|---|
| Spain, Portugal | PRs, each at war with the NPR **Tunis** |
| Turn Order | Portugal before Spain |
| Board | Portugal occupies **Algiers** (a Tunisian de jure Province). Spain occupies **every other** Tunisian de jure Province. |

## The question
Does Spain have a Total Victory, and when can it use it?

## Resolution, step by step
1. **Automatic White Peace?** No. Provinces are occupied.
2. **Total Victory step?** No. Neither PR occupies *all* of Tunis's de jure Provinces on their own (§10.1 step 2).
3. **Remaining wars, Portugal first.** Portugal has only a Partial Victory (or none), and chooses **Keep Current Board State**: it keeps Algiers (p.30).
4. **Spain's turn.** Algiers is no longer a Tunisian Province. Spain now occupies **all of Tunis's remaining de jure Provinces**, so Spain has a Total Victory *now*, and can enforce any term, including Full Annexation.
5. **Alternative:** if Portugal had instead *returned* Algiers, Spain would not hold all of Tunis, and no Total Victory would arise.

## Why (the intent)
Total Victory is checked whenever it matters, not only once. Turn Order is a real lever: Portugal's choice decides what Spain can do (Atlas; Mikhs says the designer explained it the same way).
